# Moonlight Plugin
##Version Guide

Legacy – A version that is no longer supported.

LTS (Long-Term Support) – A version maintained and hosted on GitHub.
- Provided for cases where the software does not work on older devices or when an older version is specifically required.

Stable – The most recent version within the LTS category.
- This tag is assigned to the latest available LTS release.

Newest
- Optimized for modern, up-to-date devices.

Beta
- Includes the latest features, but may not yet be fully stable.
